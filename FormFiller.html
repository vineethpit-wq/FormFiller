FEDNET - Important Instructions

Step 1: Please check Drisya → Customer View → Fednet and see whether FEDNET username and password is available for the customer.

Step 2: If the same is not available for the customer, proceed with Retail Fednet Application form

Step 3: If only view option is given to constitutions like Trust, Society, Company, Association, Partnership..., to enable e-commerce transaction facility for making Govt related fund transfer, Electricity bill payments... ensure that:

  • Customer has been onboarded to FedOne
  • The same resolution along with Indemnity bond (available in additional docs) has to be used to onboard them in Fednet
